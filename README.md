# Cohabiter avec les êtres animaux liminaires : que faire ?

Outil en ligne de la **Communauté Droit animalier Québec (DAQ)**, pour les municipalités et les citoyens.
Il suit l'arbre de décision de la méthode, étape par étape (ÉTAPE 1 à 9, MESURES A, B, C et D, ÉCHEC).

**Site : https://carlosdu31.github.io/daq-outil-cohabitation/**

**Statut : version de travail (novembre 2026).** Les contenus sont en cours de validation par la DAQ et évolueront au fil des réunions.

## Fichiers
- `index.html` : la page et son fonctionnement (ne pas modifier sans connaissances en HTML/JavaScript).
- `contenu.js` : **tous les textes** (situations, causes, mesures, délais, 22 fiches espèces, exemples). C'est le seul fichier à modifier pour changer un texte.
- `logo-daq.png` : logo de la DAQ.
- `photos/` : une photo par espèce (Wikimedia Commons ; auteur et licence indiqués dans `contenu.js` et sur chaque fiche).

## Modifier un texte
1. Ouvrir `contenu.js` sur GitHub, cliquer sur le crayon (« Edit this file »).
2. Changer le texte **entre les guillemets**, sans retirer les guillemets ni les virgules.
3. Cliquer sur « Commit changes ». Le site se met à jour en une à deux minutes.

Règles de rédaction : écrire « être animal » / « êtres animaux », jamais « animal » seul ; « étape par étape » ; couleurs : vert = mesures A et B, orange = mesure C, rouge = mesure D (échec), violet = problème connu, mais rien n'est fait.

## Mettre l'outil sur le site de la DAQ
Le site est publié avec GitHub Pages. On peut mettre son lien sur daq.quebec (bouton ou lien), ou l'intégrer dans une page avec une balise `<iframe>`.

## Le bilan (étape 9)
- « Imprimer ou enregistrer en PDF » : une page de bilan avec le logo et la date (choisir « Enregistrer au format PDF » comme imprimante).
- « Envoyer le bilan à la DAQ » : ouvre le logiciel de courriel de la personne, avec le bilan déjà rédigé, adressé à info@daq.quebec. Le PDF se joint à la main.
- Un envoi automatique (sans logiciel de courriel) demanderait un service externe de formulaire ; ce n'est pas en place.
